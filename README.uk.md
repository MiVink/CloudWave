# Cloudwave

**Тиха, нативна оболонка для SoundCloud на робочому столі.**

[English](README.md) · Українська

Cloudwave не клонує SoundCloud і не завантажує музику. Він відкриває справжній
soundcloud.com у захищеному `<webview>`, прибирає сайтовий header, рекламу,
cookie-стіну та промо-блоки — і будує навколо нього власний інтерфейс:
заголовок вікна, бічну панель, домашній екран, плеєр, режим фокусу, командну
палітру та налаштування.

![Головний екран Cloudwave](screenshots/home.png)

## Що вже працює

- **Нативна рамка вікна** — кастомний title bar, керування вікном, збереження
  розміру та позиції між запусками.
- **Домашній екран** замість екрана входу: швидкі переходи, останні треки,
  підказки гарячих клавіш. SoundCloud відкривається лише тоді, коли це потрібно.
- **Живий плеєр** — назва, артист, обкладинка, прогрес, гучність, лайк, shuffle
  та repeat синхронізуються зі справжнім плеєром SoundCloud.
- **Відтворення переживає навігацію** — пункти бічної панелі маршрутизуються
  всередині SPA, тому `<audio>` не перемонтовується. Справжнє завантаження
  сторінки використовується лише як резервний шлях, коли маршрут не вдалося
  застосувати.
- **Справжній вхід** — Google, Facebook, Apple та email працюють. OAuth
  відкривається в контрольованому дочірньому вікні на тій самій постійній
  партиції й обмежений HTTPS-allowlist провайдерів. Усе інше відкривається в
  системному браузері.
- **Чесна картка сесії** — бічна панель читає ім'я та аватар, які SoundCloud
  рендерить у власному header. Вона ніколи не читає cookie, токени чи паролі;
  `unknown` — допустимий стан, показаний як «Checking session…».
- **Бічна панель знає, де ви** — активний пункт слідує за URL webview лише коли
  webview видимий, тому фонове прогрівання не перехоплює підсвічування.
- **Контент на всю ширину** — інжектований CSS знімає обмеження контейнерів
  SoundCloud, ставить праву колонку під основну та перетворює фіксовані
  п'ятиколонкові сітки на `auto-fill`. У Charts більше немає порожньої правої
  колонки.
- **Чіткі обкладинки** — URL мініатюр підвищуються до більших варіантів
  SoundCloud у site preload, в історії та захисно під час рендеру.
- **Командна палітра** (`Ctrl+K`) — навігація, пошук, перемикання режимів.
- **Режим фокусу** (`F`) — велика обкладинка, хвиля, транспорт і керування
  гучністю без відволікання.
- **Налаштування** (`Ctrl+,`) — п'ять акцентів, зменшення анімацій, приховування
  реклами, «завжди зверху», очищення кешу, перезапуск, версії Electron/Chrome,
  а також юридичні посилання SoundCloud, які інакше зникають разом із
  прихованим сайтовим футером.
- **Медіа-клавіші** та глобальні скорочення для play/pause, next, prev.
- **Детерміновані обкладинки** для треків без artwork — стабільний градієнт із
  seed, без випадковості між перезапусками.

## Швидкий старт

Потрібні Node.js 20+ та npm. У PowerShell використовуйте `npm.cmd` — виклик
`npm.ps1` може бути заблокований політикою виконання.

```powershell
npm.cmd install
npm.cmd run dev
```

Інші команди:

```powershell
npm.cmd run typecheck    # перевірка типів main/preload і renderer
npm.cmd run build        # продакшн-збірка в out/
npm.cmd start            # запуск зібраного застосунку
npm.cmd run screenshots  # детерміновані скріншоти демо-режиму
npm.cmd run verify:live  # жива перевірка webview + preload + снапшот плеєра
npm.cmd run dist         # Windows-інсталятор (electron-builder)
```

## Керування

| Клавіші | Дія |
| --- | --- |
| `Space` | Play / pause |
| `←` / `→` | Перемотати на 5 секунд |
| `↑` / `↓` | Гучність |
| `Ctrl+←` / `Ctrl+→` | Попередній / наступний трек |
| `Ctrl+K` | Командна палітра |
| `Ctrl+,` | Налаштування |
| `F` | Режим фокусу |
| `M` | Mute |
| `L` | Like |
| `S` | Shuffle |
| `R` | Repeat |
| `H` | Домашній екран |
| `/` | Фокус на пошук |
| `Alt+←` / `Alt+→` | Назад / вперед в історії webview |
| `Ctrl+R` | Перезавантажити сторінку |
| `Esc` | Закрити оверлей |

Коли фокус перебуває всередині webview, діють скорочення самого SoundCloud.

## Як це влаштовано

```
src/main/        Electron: вікно, IPC, медіа-клавіші, захист webview, політика popup
src/preload/     міст window.desktop + скрипт, що живе всередині soundcloud.com
src/renderer/    React-оболонка, компоненти, стилі, хуки
src/shared/      спільні типи плеєра, налаштувань та обкладинок
scripts/         скріншот-харнес і жива перевірка
docs/en/         дизайн і roadmap (англійською)
docs/uk/         дизайн і roadmap (українською)
```

`src/preload/site.ts` раз на 400 мс знімає стан сайтового плеєра (назва, артист,
обкладинка, позиція, тривалість, гучність, лайк) і надсилає його в renderer через
`sendToHost('sc:player')`. Команди з нашої панелі повертаються назад через
`send('sc:command', …)`. Усі селектори — best-effort: якщо сайт змінить розмітку,
плеєр має деградувати, а не ламатися.

Навігація використовує роутер самого сайту. Бічна панель надсилає команду
`navigate`, preload клікає відповідний якір, і лише якщо URL не змінився за
~900 мс, хост відкочується до `loadURL`. Саме цей резервний шлях зберігає
відтворення під час переходів між Home і розділами.

Вхід обробляється в main-процесі. `applyPopupPolicy()` захищає кожне дочірнє
вікно (`contextIsolation`, без Node integration, партиція `persist:soundcloud`)
і дозволяє навігацію всередині застосунку лише для HTTPS-провайдерів зі списку;
усе інше відкривається в системному браузері.

Детальніше: [AGENTS.md](AGENTS.md), [docs/uk/DESIGN.md](docs/uk/DESIGN.md),
[docs/uk/ROADMAP.md](docs/uk/ROADMAP.md).

## Демо-режим

Для рев'ю дизайну без мережі відкрийте renderer з `?demo=1` (так робить
`npm.cmd run screenshots`). Демо не створює webview, використовує seeded-чергу
треків і дозволяє перемикати сцени через `window.__cloudwave.demo('home' | 'web'
| 'immersive' | 'palette' | 'settings')`.

## Мови документації

Англійська — основна локаль. Українська живе поруч і повторює ту саму структуру,
тому нова мова — це копія дерева, а не переписування:

```
README.md            README.uk.md            README.<locale>.md
docs/en/DESIGN.md    docs/uk/DESIGN.md       docs/<locale>/DESIGN.md
docs/en/ROADMAP.md   docs/uk/ROADMAP.md      docs/<locale>/ROADMAP.md
```

Тексти інтерфейсу залишаються англійськими в кожній локалі: оболонка — один
продукт, і суміш перекладеної навігації з англійським каталогом SoundCloud
читається гірше за послідовну англійську рамку.

## Обмеження

- SoundCloud — React SPA з нестабільними класами; частина селекторів може
  зламатися після їхнього оновлення.
- Персональна бібліотека, лайки та завантаження потребують входу всередині
  вбудованої сторінки.
- Cloudwave не пов'язаний із SoundCloud і не є офіційним клієнтом.
- Застосунок не завантажує та не зберігає аудіофайли.
- Хост не бачить подій клавіатури, коли фокус усередині webview.
