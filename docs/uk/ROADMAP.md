      сітки плиток `auto-fill`, жодної порожньої правої колонки в Charts

- [x] Документація, готова до локалей: англійська основна, українська поруч

## Ідеї під питанням

- Офлайн-кеш обкладинок (без кешування аудіо).
- Власні плейлисти поверх SoundCloud (потребує API або локального сховища).
- Компактний режим «mini player» поверх інших вікон.
- Інтеграція з Discord Rich Presence.

## Принципи пріоритизації

1. Спочатку те, що ламає відтворення або робить застосунок непередбачуваним.
2. Потім те, що робить щоденне використання швидшим (клавіатура, tray, історія).
3. Лише потім косметика та нові поверхні.

Кожен пункт має завершуватися перевіркою: `typecheck`, `build`, скріншот або
живий тест. Без доказу — не «готово».
